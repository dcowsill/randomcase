# RaNdoMcASe

This is a stupid package that I wrote to learn how to write Sublime Text packages and submit them to Package Control.

Also because I think it's funny.

## Installation

Install `RandomCase` via [Package Control](https://packagecontrol.io/packages/RandomCase). Works with Sublime Text 3 and 4.

## Usage

Select some text (or just put the cursor in a word) and run either:

- **Edit → Convert Case → RaNdoM CASE**
- **Convert Case: rAnDOMcASe** from the Command Palette

Multiple selections and cursors are supported.
